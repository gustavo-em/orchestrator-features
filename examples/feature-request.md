# Tarefa

Adicionar uma tela de recuperação de senha ao aplicativo React Native.

# Critérios de aceitação

- O usuário consegue solicitar recuperação usando um e-mail válido.
- O formulário explica erros de validação de forma acessível.
- Existem estados de envio, sucesso, erro e ausência de conexão.
- O teclado e a navegação de retorno funcionam em iOS e Android.
- Os componentes reutilizam o design system existente.
- Os testes relevantes passam.
